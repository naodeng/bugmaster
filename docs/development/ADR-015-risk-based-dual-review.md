# ADR-015：基于风险的代码与安全扫描

**状态：已接受。原决策日期：2026-11-18；项目所有者修订日期：2026-11-22。**

## 背景

BugMaster 由单一项目所有者维护，无法稳定获得独立 PR 审核者。Q15 的真人 PR 签署要求会阻塞日常开发。项目所有者决定以 Codex 代码与安全扫描作为 PR 审查依据，并由所有者手动合并。

## 决策

Q15=D：每个 PR 都由 Codex 对准确 head 执行代码扫描；R2、R3 变更还须对同一 head 执行安全扫描。记录可定位的发现、影响、验证依据和扫描对应的 commit。可修复的问题先修复并复扫；仍有实质风险或方案取舍时，说明选项与影响，由项目所有者决定。所有者查看扫描结果后手动合并。Q15 不要求独立真人审核或签署，也不允许自动合并。

## 后续决策

若后续证据显示这项流程存在实质问题，Codex 应说明证据和影响，再与项目所有者讨论或请所有者选择；Codex 不得单方面恢复独立真人 Q15 签署要求。

## 与 Q16 的关系

Q16=B 保持不变。公开 Release 仍要求 Release Initiator 和不同的 Independent Release Reviewer 针对同一固定 Commit、Manifest 和制品摘要授权。Q15 的 PR 扫描与手动合并不能替代 Q16，也不能被描述为真人批准。

## 变更记录

- 2026-11-22：项目所有者将 Q15 从 B 修订为 D，以 Codex 代码/安全扫描和所有者手动合并取代独立真人 PR 签署。旧 TDD、PR 和审查记录保留当时状态，不代表现行规则。
